# MealBridge — Smart Canteen Food Rescue Frontend

Responsive React + Vite frontend prototype with three roles:

- **Admin:** overview, user management, donations, collection requests, impact reports, settings.
- **Donor:** register/login, dashboard, register surplus food, my donations, donation history, profile.
- **Organizer:** register/login, dashboard, available food, request collection, collection history, profile.

## Run
1. Install Node.js LTS.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL Vite displays.

## Important
This is the first frontend-only prototype. Authentication and data are demo/local browser state; they are not secure production authentication. Connect it to your Spring Boot/API backend for real accounts, persistent data, and permissions.
